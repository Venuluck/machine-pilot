# MachinePilot — static GitHub Pages deployment

Exported from the CM Cloud AI Launch project and adapted into a fully static demonstration website.

## Pages
- `/` Home
- `/directory/` Six demonstration machine listings
- `/about/` Project scope
- `/contact/` Informational contact page (no form)

## Deploy on GitHub Pages
1. Create a public repository named `machine-pilot`.
2. Upload the **contents** of this folder (not the ZIP or enclosing folder) to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. After GitHub Pages finishes publishing, open `https://YOUR-USERNAME.github.io/machine-pilot/`.
6. Test Home, Machine Directory, About, Contact, and the mobile navigation menu.

No database, form submission, external API, external image, framework or build step is required. The site is a static demo; equipment listings are placeholders.
